# 0G Mainnet Guide

Grand Valley's 0G entry point remains in this repository. The actively maintained scripts, operational guides, version manifest, and tests live in [Valley of 0G Mainnet](https://github.com/hubofvalley/Valley-of-0G-Mainnet).

## Quick Start

```bash
bash <(curl -s https://raw.githubusercontent.com/hubofvalley/Mainnet-Guides/main/0g%20\(zero-gravity\)/resources/valleyof0G.sh)
```

The local loader delegates to the current `valleyof0G.sh` in the dedicated repository.
