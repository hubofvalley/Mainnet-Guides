# Gnoland Mainnet Guide

Grand Valley's maintained Gno.land mainnet launcher and operational guides live in [Valley of Gnoland Mainnet](https://github.com/hubofvalley/Valley-of-Gnoland-Mainnet).

## Quick Start

Run as the node OS user:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/hubofvalley/Valley-of-Gnoland-Mainnet/main/resources/valleyofGnoland.sh)
```

The menu keeps the established Valley of Gnoland UX while targeting the live `gnoland-1` mainnet.

| Field | Value |
|---|---|
